# 문제 제목
구현 - 데이터센터 점검 로봇
## 문제 이해

N X M 크기의 지도에서 
`.` : 이동 가능한 칸
`#` : 이동 불가능한 칸

명령 대로 움직이되 움직일 위치가 이동이 불가능한 칸이면 무시

총 이동한 횟수
## 접근법

`0` : 움직일 수 없는 칸
`1` : 움직일 수 있는 칸

테두리는 0으로 패딩 => 테두리 이상으로 접근하지 않게 사전 차단

```
cnt (총 이동 횟수), startx, starty, matrix[n+2][m+2]

for: 1 ~ 명령어 횟수
    dx, dy, steps(이동 횟수), dir(이동 방향)
    dir : U(Up) : dy-1
        : D(Down) : dy+1
        : L(Left) : dx-1
        : R(Right) : dx+1

    while(steps > 0)
        이동할 칸 = 0 : break
        
        cnt++;
        startx += dx, starty += dy, steps--
        
```

## 복잡도

- 시간 복잡도: O(N × M + S)
  - 지도 저장 : O(N × M)
  - 모든 이동 명령 수행 : O(S)
- 공간 복잡도: O(N × M)
  - - 이동 가능 여부를 저장하는 2차원 배열을 사용한다.
