# 문제 제목
[2026-10-30] 배열·해시 - 최초 중복 요청

## 문제 이해
서버가 처리한 요청 -> 중복 요청이 있는 순간 찾기
중복 요청이 발견 -> 요청 ID 와 중복 요청이 등장한 위치
중복이 없다면 -1

## 접근법
n : 서버 개수
map(서버Id, 인덱스)

for(i : 0 ~ n)
    if(map.has(서버 Id))  
        return 인덱스+1

    if(!map.has(서버Id))
        map.add(서버Id, 인덱스)

return -1

## 복잡도

- 시간 복잡도: O(N)
- 공간 복잡도: O(N)
