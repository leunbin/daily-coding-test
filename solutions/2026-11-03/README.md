# 문제 제목

투 포인터·슬라이딩 윈도우 - 요청량 제한 구간

## 문제 이해

N분동안 받은 요청 수가 분 단위로 주어짐
연속된 구간의 요청 수 합 <= L 인 가장 긴 구간의 길이

## 접근법
```
N : 분
L : 제한값
start = 0, end = 0 max = 0 sum = end

for(end: 0 ~ N )
    sum += end
    
    while(sum > L)
        sum -= start
        start++
    
    max = Math.max(max, end-start+1)
    
      
sout(max)
```
## 복잡도

- 시간 복잡도: O((N)
- 공간 복잡도: O(N)
