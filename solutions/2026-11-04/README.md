# 문제 제목

기간별 재고 변동 조회

## 문제 이해

N일의 재고 변동량 : 양수 - 입고 / 음수 - 출고
L일부터 R일까지의 재고 변동량 합 구하기 (날짜는 1부터)

## 접근법
```declarative
stocks[] (누적합)
Q : 조회 수

for(i: 0 ~ Q) 
    sout(stocks[R]-stocks[L-1])
```

## 복잡도

- 시간 복잡도: O(N + Q)
- 공간 복잡도: O(N)
